# CopperScript v1

**Мощный фреймворк для CopperCube 6**  
Расширяет возможности движка: переменные, условия, таймеры, триггеры, сохранения и многое другое.

![CopperScript Icon](CopperScriptIcon.png)

---

## Возможности

### Actions (Действия)
- `Init Core` — инициализация системы, загрузка сохранений
- `Set Variable` — установка переменной
- `Get Variable` — получение значения
- `Check Condition` — проверка условия
- `If-Else Statement` — полноценный если-иначе
- `If-Else-If Chain` — цепочка условий
- `Switch Statement` — множественный выбор
- `Add to Variable` — прибавление/вычитание
- `Set Random Value` — генерация случайного числа
- `Compare Two Variables` — сравнение переменных
- `Reset All Variables` — полный сброс
- `Save Game` / `Load Game` — сохранение/загрузка
- `Wait X Seconds Then Execute` — задержка

### Behaviors (Поведения)
- `Advanced Trigger` — триггер с условиями: старт, клик, столкновение, таймер, клавиша, изменение переменной

---

## Быстрый старт

1. Скопируй все `.js` файлы из `actions/` и `behaviors/` в папку `Extensions/` твоего проекта
2. Создай объект `GameManager` в сцене
3. Добавь на старт действие `CopperScript: Init Core`
4. Готово! Все действия доступны в редакторе

## Технические детали

- **Глобальное хранилище**: `window.csCore.vars`
- **Автосохранение**: все переменные сохраняются в `localStorage`
- **Логирование**: `window.csCore.log(msg)` выводит в консоль
- **Поддерживаемые типы**: числа, строки, логические значения
